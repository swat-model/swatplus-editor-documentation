# SWAT+ Editor Documentation

Documentation for [SWAT+ Editor](https://github.com/swat-model/swatplus-editor) built by [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Installing and running the source code

1. Install [Python 3](https://www.python.org/)
2. Install packages: `pip install -r requirements.txt`
3. Run the source code with live reloading as you make changes: `mkdocs serve --livereload`

## Deploy

A GitHub Actions workflow (.github/workflows/deploy.yml) builds the site and publishes them to GitHub Pages on every push to main.
